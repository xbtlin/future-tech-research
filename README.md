# Future Tech Research — 未来 3 年哪些新技术会火

研究窗口：**2026 – 2029**

这不是写给风险投资人的"热门赛道清单"，而是一个**持续演进的判断框架**：当新技术出现时，用一套可复用的标准给它打分，避免被 hype 带偏，也避免错过真正的拐点。

---

## 为什么是 3 年

- **< 1 年**：已经在爆发的东西，新闻里满眼都是，不用研究
- **> 5 年**：不确定性太大，多数变量今天还看不到
- **3 年窗口**：技术已经过了 demo 阶段、开始有第一批规模化应用、产业链拐点即将到来——能判断"是不是真的"而不是"是不是酷"

## 评估维度（见 `frameworks/scorecard.md`）

每项技术按五个维度打分（★1–5）：

| 维度 | 问什么 |
|---|---|
| **技术成熟度** | 从 lab demo 到量产的差距？关键瓶颈还剩几个？ |
| **经济性** | 单位成本下降曲线？什么时候跨过"能用"到"便宜到不用白不用"？ |
| **需求真实性** | 有没有付费客户？是痛点还是痒点？可证伪的销售数据？ |
| **生态成熟度** | 上下游是否齐备？标准、人才、工具链？ |
| **3 年拐点概率** | 3 年内出现规模化转折的概率（0–100%） |

## 研究原则（最高优先级）

- **事实先行**：数据 > 专家观点 > 媒体叙事。每个关键判断至少 2 个独立来源交叉
- **呈现正反两面**：每条预测附反面论据（"但另一方面..."），让读者自己权衡
- **可证伪**：结论写成可以被未来验证/推翻的具体命题，避免"万能正确"
- **追踪复盘**：每季度回看过往预测，错的先承认、再归因
- **拒绝赛道名词化**：不写"Web3 会起飞"，要写"XX 链上稳定币结算量 2027 年超过 $X"
- **对抗核查**：每条关键数字过 3 票独立反驳，2/3 判死；**被推翻的清单与存活的结论一起归档**（2026-Q3 实测杀伤率 44%，即检索出的"看起来有来源的数字"里近一半经不起核查）
- **区分"未取证"与"无进展"**：某维度本轮零结论存活时，必须写成"本轮未取证"。写成"无进展"会在下季度回看时制造假趋势

## 当前聚焦：LLM 九大能力维度

第一阶段研究范围收敛到**大模型能力/工程维度**（而非泛科技）。9 个互斥的演进方向：

1. **Reasoning** — 数学/逻辑/多步规划的深度思考（o-series、R1 路线）
2. **Agentic** — 长任务自主执行、工具调用、状态维护（模型本身能力）
3. **Harness / Scaffolding** — 工程层：上下文管理、工具编排、错误恢复（Claude Code、Cursor、MCP）
4. **Coding** — 从代码补全到仓库级自主交付
5. **Multimodal** — 视觉/音频/视频理解与生成、VLA
6. **Long-context / Memory** — 百万 token 窗口 + 长期记忆架构
7. **On-device / Efficiency** — 量化/MoE/端侧推理/推理硬件
8. **Post-training** — RLHF / RLVR / GRPO / self-play / 合成数据
9. **World Models** — 视频预测 + 物理一致性 + 机器人 foundation

每个方向按五维评分卡跟踪，每季度汇总。

**最新更新**：[`reports/2026-Q3-九大方向更新.md`](reports/2026-Q3-九大方向更新.md)（2026-08-14，差分报告）
**全景基线**：[`reports/2026-Q2-LLM九大方向调研.md`](reports/2026-Q2-LLM九大方向调研.md)（2026-04-14）

**专题研究**（跨维度的单个问题）：
- [领域大模型是不是真命题？——兼论"千亿参数达到万亿效果"的理论边界与工程路径](research/Domain-Models/领域模型真伪与千亿逼近万亿-202608.md)（2026-08-15）：从零预训练的行业基座已被证伪，"通用基座 + 领域后训练 + 推理协同"成立且 2026 年有一批跑赢前沿模型的实证；千亿逼近万亿在封闭任务分布上可行、在开放长尾知识上不可行，分界线是知识容量（技能可蒸馏、知识随总参数走）

- [自动后训练综述（2025.08–2026.08）](research/Post-training/自动后训练综述-202608.md)（2026-08-13）

> Q3 一句话：最亮的数字在推理（ARC-AGI-2 84.58% → 92.5%），但最重要的发现是**量尺本身在塌** ——Epoch 承认 FrontierMath 有 42% 题目出错、METR 承认时间视野尺在 16 小时以上不可靠、UC Berkeley 用一个"零能力"agent 把 10 个主流 agent 榜单中的 9 个刷到接近满分。**所有以 benchmark 分数为唯一依据的拐点判断，置信度下调一档。**

## 工作流

```
新技术 → 初筛（研究框架 checklist）→ 立项 research/<tech>/
     ↓
  拉取一手数据（论文、财报、招股书、专家访谈）
     ↓
  按五维评分 → 写 3 年拐点判断 → 列反面证据
     ↓
  季度复盘（reports/YYYY-QX.md）
```

```bash
# 新开一个技术方向

```
