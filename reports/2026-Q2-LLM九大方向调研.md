## 1. Reasoning

### 代表性论文/模型（2025-2026）
- [DeepSeek-2025.01 / Nature 2026] **DeepSeek-R1**：纯 RL（GRPO）无需人工标注推理轨迹，激发出自反思/验证等涌现推理模式 — [arXiv 2501.12948](https://arxiv.org/abs/2501.12948) / [Nature](https://www.nature.com/articles/s41586-025-09422-z)
- [DeepSeek-2026.04] **DeepSeek-R2**：32B 稠密 MIT 开源权重，单张 4090 可跑，AIME 2025 达 92.7% — [blog](https://deepseek.ai/blog/deepseek-r2-ai-model-launch-2025)
- [Anthropic-2025.05] **"Reasoning Models Don't Always Say What They Think"**：CoT 忠实性测定，Claude 3.7 41%、R1 19% — [arXiv 2505.05410](https://arxiv.org/abs/2505.05410)
- [Google DeepMind-2026] **Gemini 3 Deep Think**：ARC-AGI-2 与 FrontierMath 双料领先 — [ARC Prize](https://arcprize.org/leaderboard)
- [Imbue-2026.02] **"Beating ARC-AGI-2 with Code Evolution"**：代码进化式搜索，Gemini 3.1 Pro 88.1% → 95.1% — [Imbue](https://imbue.com/research/2026-02-27-arc-agi-2-evolution/)

### 当前 SOTA（2026-04）
- **FrontierMath**：GPT-5.4 Pro ~50%；Gemini 3 Deep Think 40%+
- **AIME 2025**：o4-mini+tools 99.5%（无 tools 88.9%）；Grok 3 ~93%；DeepSeek-R2 92.7%
- **ARC-AGI-2**：Gemini 3 Deep Think 84.6%（原生）；Agentica+Opus 4.6 85.28%；Poetiq 进化式 95.1%
- **GPQA Diamond** 已基本饱和在 85–90%
- 格局：闭源 GPT-5.x Pro 与 Gemini 3 Deep Think 并列前沿，开源第一梯队 DeepSeek-R2、Kimi K2.5 Thinking

### 未解决的核心问题
1. **CoT 忠实性**：Anthropic 证据显示模型用了隐藏提示但大多数情况下不在推理链中承认；结果导向 RL 甚至加剧不忠实，使 CoT 监控作为对齐手段不可靠
2. **长推理成本/延迟**：单道 ARC-AGI-2 题 $2–30，Deep Think 单次响应数十秒到数分钟，商用 ROI 不清
3. **跨域泛化**：数学/代码上的 RL 推理能力迁移到开放 agent 多步任务时 naive sampling 有明显边际递减

### 3 年内可能的突破（可证伪）
1. **2028 年底前**，出现开源 <50B 推理模型在 FrontierMath 上 ≥40%，单题推理成本低于当前 GPT-5.4 Pro 的 1/20。证伪条件：届时最好的 <50B 开源模型 FrontierMath 仍 <25%
2. **2027 年前**，attribution graphs 路线产出首个"可审计"推理模型，真实内部推理与输出 CoT 的因果一致率 >80%。证伪条件：最佳忠实性仍 <50%

### 反面观点
Epoch AI / 多篇 2026 分析指出：test-time compute 扩展呈明确幂律，agent 多步任务很快到 saturation point；o3→o4、R1→R2 每代同 benchmark 提升幅度已从 20pp → 5pp，暗示单纯加长思考预算已进入边际递减，真正下一跳必须来自架构或训练目标的改变。

## 2. Agentic

### 代表性论文/模型（2025-2026）
- [Anthropic-2026.02] **Claude Opus 4.6**：agentic 训练聚焦长程任务，METR 实测 14.5 小时任务时长，SWE-Bench Verified 80.8% — [Anthropic](https://www.anthropic.com/research/long-running-Claude)
- [METR-2026.01] **Time Horizon 1.1**：frontier 任务时长 2024-2025 doubling 从 7 个月缩到 4 个月 — [METR](https://metr.org/blog/2026-1-29-time-horizon-1-1/)
- [Cemri et al., ICLR 2025] **"Why Do Multi-Agent LLM Systems Fail?"**：MAST 分类法，14 种失败模式，开源 MAS 任务失败率 41–86.7% — [arXiv 2503.13657](https://arxiv.org/html/2503.13657v1)
- [Meta FAIR-2025.09] **ARE / GAIA2**：1120 个可验证移动端场景 — [arXiv 2509.17158](https://arxiv.org/html/2509.17158v1)
- [OpenAI-2024, 仍基准] **MLE-Bench**：o1-preview+AIDE 仅 16.9% Kaggle 铜牌 — [GitHub](https://github.com/openai/mle-bench)

### 当前 SOTA
- **SWE-Bench Verified** 前五：80.0–80.9%（Opus 4.5/4.6、Gemini 3.1 Pro、MiniMax M2.5、GPT-5.2）— OpenAI 已弃用转 **SWE-Bench Pro**（最佳 46%）
- **GAIA**：人类基线 92%，SOTA ~65%，Level 3 (≤50 steps) 仍是瓶颈
- **OSWorld** 50 步 SOTA 34.5%；**TAU-Bench** pass^k 随 k 指数衰减
- **METR**：步数每翻一倍，成功率近似线性下降；>8h 任务成功率仍 <50%

### 未解决的核心问题
1. **长程 credit assignment 与错误累积**：MAST 数据显示失败归因自动化只 53.5% 准确；context 无界增长 + handoff 延迟叠加导致 17x 误差放大
2. **Self-correction vs self-delusion**：Reflexion 在 verifier 稀疏时常自证错误答案；OpenAI 审计发现 frontier 模型能复述 SWE-Bench gold patch
3. **跨 session 记忆与策略一致性**：TAU-Bench 政策遵循任务中，同一模型对同一用户多次会话决策不一致

### 3 年内可能的突破（可证伪）
1. **端到端 RL on 真实工具轨迹**：2027 年前纯模型层把 OSWorld 50-step 推到 >60% 且不依赖外部 planner harness，则"模型本身自主性"可继续 scale；否则 plateau 在 40% 附近
2. **长期记忆 + 子目标分解原生架构**：某模型在 GAIA Level 3 和 METR >8h 任务同时达到人类 >80% 成功率且不需要 workflow scaffolding，则 agentic 进入"可交付"阶段

### 反面观点
Designative "HITL is Not a Strategy" (2026.04) 与 dev.to 综述指出：LLM 本质概率性，在金融、医疗、合规场景失败成本不对称；多 agent 系统 41–86.7% 失败率意味着单步 95% 准确，20 步链路成功率也 <36%。结论：**商业价值只来自"agent 起草、人定稿"的 HITL 模式**，纯自主执行是研究题非产品题。

## 3. Harness / Scaffolding

### 代表性工作（2025-2026）
- [Anthropic-2024.11 / Linux Foundation-2025.12] **Model Context Protocol (MCP)**：三大模型厂全接入（OpenAI 2025.03、Google 2025.04、Anthropic 2025.12 捐赠给 Linux Foundation）；SDK 月下载 9700 万 — [Anthropic](https://www.anthropic.com/news/donating-the-model-context-protocol-and-establishing-of-the-agentic-ai-foundation)
- [Chroma-2025.07] **Context Rot 技术报告**：18 个前沿模型输入变长性能非均匀衰减，lost-in-the-middle 30%+ 精度下降 — [research.trychroma.com](https://research.trychroma.com/context-rot)
- [Anthropic-2025.09] **Effective Context Engineering for AI Agents**：compaction、structured note-taking、multi-agent subagent 三件套 — [Anthropic](https://www.anthropic.com/engineering/effective-context-engineering-for-ai-agents)
- [arXiv 2510.04618-2025.10] **Agentic Context Engineering (ACE)**：把 context 视作会进化的 playbook，+10.6%/+8.6% — [arXiv](https://arxiv.org/abs/2510.04618)
- [Cognition-2026.02] **Devin 2.2**；[Microsoft-2025] **AutoGen v0.4** 异步事件驱动重写；**LangGraph v1.0** durable execution

### 当前 SOTA
- **编程**：SWE-Bench Verified 80.9%（Opus 4.5），Claude Code 独立 scaffold 58.0%
- **计算机使用**：OSWorld-Verified 开源 **Holo3 (10B) 78.85%** 登顶（2026 初）；GPT-5.4 75.0% 超人类基线 72.4%
- **MCP 生态**：已成 de facto 标准

### 未解决的核心问题
1. **Context rot / 长会话状态退化**：18 个前沿模型无一幸免；靠 compaction + 外部 memory 绕开而非真正解决
2. **多 agent 协作与人机交接 UX**：谁决策、何时打断、如何汇报仍无共识
3. **工具协议标准化**：MCP 事实上赢了，但认证、代码执行安全、可组合性仍在演进

### 3 年内可能的突破（可证伪）
1. **MCP 成为 agent 界的 USB-C**：2029.01 前 MCP（或 fork）承载 ≥80% 新商业 agent 的工具调用
2. **Harness 层出现统一"Agent OS"抽象**：memory/tool/handoff/HITL 成为操作系统原语，scaffolding 代码量相比 2025 下降一个数量级

### 反面观点
底模派认为 harness 是临时脚手架：Devin 早期 13.86% SWE-bench 曾是"harness 奇迹"，两年后被裸模型碾压；随着原生 computer use、原生 memory、原生 MCP 进入底模，第三方 harness 差异化窗口被持续吃掉，最终只剩 IDE UX 和企业分发渠道。

### 代表性论文/模型（2025-2026）
- [OpenAI-2025.12 / 2026.03] **GPT-5.2-Codex / GPT-5.3-Codex**：Codex-native agentic 编程模型 — [OpenAI](https://openai.com/index/introducing-gpt-5-3-codex/)
- [Anthropic-2026] **Claude Opus 4.5 / 4.6、Sonnet 4.6**：Opus 4.5 SWE-Bench Verified 80.9%
- [Alibaba-2025.09] **Qwen3-Coder 480B-A35B**：开源 MoE 编程模型 SWE-bench 69.6%
- [DeepSeek-2025.12] **DeepSeek-V3.2**：LiveCodeBench 89.6%
- [Scale AI-2025] **SWE-Bench Pro**：1865 个多语言多文件任务，GPL+私有代码抗污染 — [Scale](https://labs.scale.com/leaderboard/swe_bench_pro_public)
- [arXiv 2512.17419] **SWE-Bench++**：11133 实例/3971 仓库/11 语言

### 当前 SOTA（2026-04）
- **SWE-Bench Verified**（已公认受污染）：Claude "Mythos Preview" 93.9%、GPT-5.3-Codex 85%、Opus 4.5 80.9%
- **SWE-Bench Pro**（抗污染）：最强仅 **46%**，OpenAI 已公开宣布停用 Verified
- **LiveCodeBench**：Gemini 3 Pro Preview 91.7%、Gemini 3 Flash 90.8%、DeepSeek-V3.2 Speciale 89.6%

### 未解决的核心问题
1. **真实大仓库的跨文件长时程修改**：Pro 46% vs Verified 93% 的落差证明模型在"多文件+多轮调试+跨模块一致性"上仍是短板
2. **基准污染与评估可信度**：Verified 已被验证可背诵 gold patch
3. **工程判断与交互**（何时 ask-for-clarification、何时拒绝需求）；小众语言/DSL/legacy 泛化

### 3 年内可能的突破（可证伪）
1. **Verifier-guided coding agents**：形式验证 + 类型系统 + property-based testing 作为内环 reward signal（SERA 雏形），32B 级开源模型逼近闭源旗舰，同时提供"正确性证书"
2. **仓库级长上下文 + 持续学习**：百万 token + 单一 codebase 的 online adaptation/memory，让模型能"长期维护一个产品"而非完成隔离 issue

### 反面观点
Freedom Preetham 等指出：SWE-bench 分数再高也不会救你在生产环境的故障——软件工程瓶颈从来不是写代码，而是理解模糊需求、驾驭遗留系统、跨团队沟通和运维判断。AI coding 会把写代码成本推向零，但"谁决定写什么、为什么写、出事谁担责"短期仍由人类承担。

### 代表性工作（2025-2026）
- [OpenAI-2025.10] **Sora 2**：原生 25s 单镜头，物理模拟 + 同步音频 — [OpenAI](https://openai.com/sora)
- [Google DeepMind-2026] **Veo 3.1 + Gemini 3 Pro**：Video-MME-v2 66.1%，支持 6 小时视频理解
- [Alibaba-2026.03] **Qwen3.5-Omni**：端到端 omni，256K 上下文、113 语种，MMMU 82.0%
- [Kuaishou-2026] **Kling 3.0** 原生 4K；ByteDance **Seedance 2.0** 唇同步领先
- [Physical Intelligence-2025] **π0.5 VLA**：在训练外的新家庭厨房可完成 10–15 分钟多阶段清洁 — [pi.website](https://www.pi.website/download/pi05.pdf)
- [Figure-2026.01] **Helix 02**：三层架构（System 0/1/2）实现像素到全身端到端控制 — [Figure](https://www.figure.ai/news/helix-02)

### 当前 SOTA
- **图像理解 MMMU**：o1 77.7%、Qwen3-Omni 82.0%；Gemini Deep Think MMMU-Pro 达 95（已超"最差人类专家"76.2%）
- **视频生成**：Sora 2 单镜头 25s 最长原生时长；Veo 3.1 速度比 Sora 2 快 30–40%；Kling 3.0 原生 4K。>30s 长一致性仍穿帮
- **视频理解**：Gemini 2.5 Pro VideoMME 84.8%；Video-MME-v2（含超长时序推理）Gemini 3 Pro 仅 66.1%
- **VLA**：π0.5 未见家庭环境可完成长程；缺统一 RoboArena 级真实世界成功率数字

### 未解决的核心问题
1. **视频生成的长时物理一致性**：>30s 后物体身份、重力、流体、碰撞频繁崩坏
2. **VLA 的 sim-to-real 与长尾泛化**：新物体/新光照/新布局下成功率陡降；真机遥操作数据是瓶颈
3. **多模态推理 < 纯文本推理**：omni 模型在需要深度链式推理的视觉/视频问题上落后同家族 reasoning 模型

### 3 年内可能的突破（可证伪）
1. **视频世界模型作为机器人/自动驾驶仿真器**：Sora/Veo 级 + 可微物理 + RL 微调给 VLA 提供无限合成数据，打穿 sim-to-real
2. **原生 omni + reasoning 融合**：GPT-5 级 omni 与 o1/Deep Think 级 test-time compute 合并，MMMU-Pro / Video-MME-v2 在 2028 前接近饱和

### 反面观点
LeCun 等持续指出：当前 diffusion/transformer 视频模型本质是像素分布拟合而非物理建模，Sora 2 被公开测出"手穿过杯子"、"液体反重力"案例；3 年内若无显式世界模型（V-JEPA 路线）突破，视频生成将停在"好看但不可信"的娱乐层——Figure/π 仍必须投入昂贵真机遥操作数据，而非用 Sora 合成训练集，就是佐证。

## 6. Long-context / Memory

### 代表性工作（2025-2026）
- [Google / Anthropic] **Gemini 2.5/3 Pro 1M–2M token**；**Claude Sonnet 4.5 / Opus 4.6 1M context**，Opus 4.6 MRCR v2 8-needle @1M 76%
- [Chroma-2025.07] **"Context Rot"**：18 个前沿模型输入变长即性能衰减 — [Chroma](https://research.trychroma.com/context-rot)
- [OSU-NLP / ICML 2025] **HippoRAG 2**：PageRank+知识图谱神经启发长期记忆，MuSiQue F1 44.8→51.9 — [arXiv 2502.14802](https://arxiv.org/abs/2502.14802)
- [Letta-2025] **MemGPT→Letta**：LoCoMo 74.0%（GPT-4o mini）— [Letta](https://www.letta.com/blog/benchmarking-ai-agent-memory)
- [AI21 / Tri Dao-Albert Gu] **Jamba + Mamba-2 SSD**：256K context KV cache 只 4GB（vs Mixtral 32GB）

### 当前 SOTA
- **原生 context**：宣传值与"有效 context"差距巨大。Gemini 3 Pro 128K 处 MRCR 8-needle 77%，**1M 处掉到 26.3%**；Opus 4.6 @1M 76% 为公开可验证最强；LongBench v2 最强 50.1% vs 人类 53.7%
- **Memory 系统**：LoCoMo SuperLocalMemory Mode C 87.7%、Letta 83.2%、Mem0 graph 68.5%；HippoRAG 2 在多跳 QA 全面超过纯 embedding RAG
- **三者对比**：LOFT（NAACL 2025）— LC 擅长静态长文深推理，RAG 擅长动态/多源，memory agent 是"对话日志专用 RAG"

### 未解决的核心问题
1. **Context rot / 深度推理塌陷**：BABILong 显示模型实际只利用 **10–20% 宣称 context**
2. **跨 session 记忆一致性与 unlearning**：无标准化的记忆冲突解决、过期遗忘、GDPR 式 unlearning 机制
3. **多 agent 共享记忆与个性化边界**：访问控制、版本冲突、权限传播几乎没有学术基准

### 3 年内可能的突破（可证伪）
1. 混合架构（Jamba/Mamba-Transformer + 稀疏 KV 压缩）把 1M 下多跳推理错误率从当前 ~25–40% 压到 **<10%**，推理成本降 5–10×
2. "Self-editing memory + 知识图谱 RAG"合流成为 Agent 运行时原语，LoCoMo 类长程任务突破 90%，跨 session unlearning 与审计有事实标准

### 反面观点
Chroma Context Rot 与 BABILong 都支持一个强观点：无论模型宣称 1M 还是 10M，注意力在 token 数上近似二次成本、信息在中段必然衰减。未来 3–5 年真正的生产架构将是 **"短工作 context（32K–200K）+ 强检索 + 结构化长期记忆 + 选择性 SSM 压缩"**，而非把所有 token 塞进窗口。

## 7. On-device / Efficiency

### 代表性工作（2025-2026）
- [Microsoft-2025.04] **BitNet b1.58 2B4T**：首个原生 1.58-bit 训练 2B 模型，性能逼近 FP16 Llama 2 — [arXiv 2504.12285](https://arxiv.org/pdf/2504.12285)
- [Microsoft-2024.11] **BitNet a4.8**：4-bit 激活 + 3-bit KV cache，仅激活 55% 参数
- [DeepSeek-2024.12→2026] **DeepSeek V3/V3.2**：671B / 37B 激活 MoE，MLA 压缩 KV，每 token 250 GFLOPS（vs 72B dense 394）
- [Microsoft-2024Q4] **Phi-4 (14B)**：MATH 80.4%，超越多数 70B dense
- [Google-2025] **Gemma 3 (270M/4B)**：270M 变体 25 轮对话耗 0.75% 电量；4B 仅 4.2GB RAM
- [Apple-2025 WWDC] **Apple Foundation Model ~3B**：端侧 2-bit QAT + KV-cache sharing；服务端首次用 Parallel-Track MoE

### 当前 SOTA
- **1B–3B 端侧模型**：Phi-4 14B MATH 80.4% 已超 2023 年 Llama-2 70B；3–4B 级别普遍达到两年前 7B 的 110–130%
- **推理成本**：a16z "LLMflation" 同等能力每年降 **10×**；GPT-4 等效能力从 2022 年底 $20/M tokens → 2026 年 $0.40/M；极端场景 900×
- **MoE**：DeepSeek V3 激活/总参数压到 **5.5%**（37B/671B）

### 未解决的核心问题
1. **端侧长上下文内存墙**：KV cache 随上下文线性增长，手机 8–12GB RAM 难撑 128K 实用上下文
2. **小模型 reasoning 天花板**：3B 以下在多步推理、长链 agent 任务上落后云端 1–2 代
3. **推理硬件 CUDA 垄断**：Groq/Cerebras/Etched 峰值 tok/s 领先，但软件栈深度锁定 Nvidia；Nvidia-Groq 2026 年 $200 亿交易进一步强化垄断

### 3 年内可能的突破（可证伪）
1. **原生低比特训练成主流**：BitNet b1.58 + FP4 路线若 scale 到 70B 开源，同 8GB 手机可跑等效今天 30B dense
2. **超稀疏 MoE + latent attention 统一端云架构**：激活比压到 2–3%、MLA 压缩 KV 10×，同一套权重端侧走小激活、云端走大激活

### 反面观点
怀疑派：(1) 前沿能力的参数下限结构性上移，端侧永远落后 2–3 代；(2) 云端 $0.05/M nano 模型已足够便宜，消费者不会为"隐私+离线"多付钱；(3) 苹果 2026 年被迫和 Gemini 合作说明端侧自研路线撑不起高端；(4) 手机功耗/散热限制使持续推理不现实。

## 8. Post-training

### 代表性论文（2025-2026）
- [DeepSeek-2025.01] **DeepSeek-R1 / GRPO**：纯 RL + 规则化可验证奖励，改写 post-training 范式 — [arXiv 2501.12948](https://arxiv.org/abs/2501.12948)
- [OpenAI-2025.04] **o3 / o4-mini**：RL 与工具使用同时 scale，官方"RL compute 将与 pretrain compute 同等规模"
- [Meta-2025] **Meta-Rewarding / SPICE**：自判 + 自出题自解题，Llama-3-8B AlpacaEval 胜率 22.9%→39.4%
- [Tsinghua-2025.04] **"Reasoning LLMs Are Just Efficient Samplers"**：RLVR 提升主要是 pass@1 的搜索压缩，非 pass@k 上限
- [arXiv 2509.07414] **Language Self-Play**：无外部数据、单模型自博弈
- [综述 arXiv 2510.08049] **PRM Survey**：PRM vs ORM 路线梳理

### 当前 SOTA
- **RLVR 已成主流**：头部实验室几乎全切到"可验证奖励 + GRPO"；DeepSeek-R1、o-series、Qwen、Kimi 均走这条路
- **合成数据规模化**：Phi 早就 >90% 合成；行业共识"合成 + CommonCrawl 混合"优于纯合成（纯合成有模型崩塌风险）
- **偏好学习共识**：**DPO 管风格，GRPO 管推理，PPO 渐退**。GRPO 省 50% 显存、无 critic

### 未解决的核心问题
1. **Reward hacking & 可验证域外推广**：创意写作、品牌语气、复杂论证没有 ground truth，Rubrics-as-Rewards 是权宜之计
2. **长程任务的信用分配**：Agentic 多步工具使用中 ORM 噪声大、PRM 标注贵；step-level 奖励仍开放
3. **小模型 RL scaling**：<7B 用 GRPO 收益有限，RL 红利可能只对强基座生效

### 3 年内可能的突破（可证伪）
1. **Self-play / 语言自博弈成为数据引擎**：SPICE、Language Self-Play 若稳定跑通，打破"人类数据天花板"，类似 AlphaZero 时刻
2. **Generative / Thinking PRM + RL 融合**：PRM 自身具备推理能力，推理时生成原则并打分，替代固定 reward model

### 反面观点
Tsinghua 2025.04 实证直指：RLVR 大多数收益是"在固定基座的采样分布上压缩搜索"，pass@k 几乎没动。若成立，则 post-training 是榨油水，真正能力跃迁仍要靠预训练 compute 和数据质量；DeepSeek-R1 的"顿悟时刻"可能只是基座里原本就存在的能力被 RL 显化。

## 9. World Models

### 代表性工作（2025-2026）
- [OpenAI-2025.10] **Sora 2**：引入更强物理规律（篮球不进会反弹而非"瞬移"）— [OpenAI](https://openai.com/index/sora-2/)
- [Meta FAIR-2025.06] **V-JEPA 2**：10 亿+小时视频自监督 + 62 小时机器人动作微调，零样本规划 65–80% pick-and-place — [Meta](https://ai.meta.com/blog/v-jepa-2-world-model-benchmarks/)
- [Google DeepMind-2025.08] **Genie 3**：文本到可交互 3D 世界，720p@24fps，一分钟级场景记忆 — [DeepMind](https://deepmind.google/blog/genie-3-a-new-frontier-for-world-models/)
- [NVIDIA-2026.02] **Cosmos Predict 2.5 / Reason 2 / Policy**：30s 长尾场景生成；LIBERO/RoboCasa SOTA — [NVIDIA](https://nvidianews.nvidia.com/news/nvidia-announces-major-release-of-cosmos-world-foundation-models-and-physical-ai-data-tools)
- [Wayve-2025.03] **GAIA-2**：多视角可控驾驶世界模型，2500 万视频序列 — [Wayve](https://wayve.ai/thinking/gaia-2/)
- [Physical Intelligence-2025.04] **π0.5**：在未见真实家庭完成 10–15 分钟级清洁
- [Google DeepMind-2025.09] **Gemini Robotics 1.5**：端侧 ≥60%、云端 ~80% 任务成功率（100 条演示内）
- [1X-2026.01] **1X World Model**：首个全身人形接触丰富未来预测器

### 当前 SOTA
- **视频一致性**：Genie 3 实时交互保持"几分钟"；Sora 2 正确保持跨镜头物体/光照/重力；>1 分钟严格物理守恒不稳定
- **可交互世界模型**：Genie 3 实时（24fps）、720p、记忆窗口 ~1 分钟（Genie 2 只有 10–20 秒）
- **机器人 policy**：Cosmos Policy LIBERO/RoboCasa SOTA；V-JEPA 2 novel object 65–80%；π0.5 全新家庭多步任务与见过环境对照组相当

### 未解决的核心问题
1. **长时序累积误差**：Genie 3 超过 1 分钟场景漂移，自回归世界模型难以保持物体永久性和刚体守恒
2. **物理先验 vs 纯数据**：现有模型没有显式刚体/流体/接触解算器，稀有事件（碰撞、液体、柔性体）外推差
3. **VLA 数据效率**：相较 LLM 的互联网文本，机器人 demo 数据量差 **4–5 个数量级**

### 3 年内可能的突破（可证伪）
1. **到 2029 年**，通用人形 VLA 在工厂结构化装配/分拣任务端到端成功率能否从 ~70–80% 跨到 **95%+，并部署在 100 家工厂以上**（而非 demo）
2. **可交互世界模型一致性窗口从 1 分钟 → 30 分钟+**，使其成为 RL agent 训练的主要 simulator，替代 Unity/Unreal

### 反面观点
LeCun 及认知派认为：纯像素/视频预测目标（Sora、Genie）浪费大量容量刻画无关纹理，学不到抽象因果结构；没有结构化物理先验（刚体解算、能量守恒、object-centric 表征）的 world model 上限有限——IntPhys 2 上视频扩散模型远逊人类婴儿水平，这也是 Meta 押注 JEPA（隐空间预测、放弃像素重建）的根本原因。

## 交叉观察（横跨 9 个方向的共同信号）

1. **Benchmark 污染已是全行业问题**。SWE-Bench Verified、MMMU 等经典基准被证明可被模型"记住"，2026 年 OpenAI 公开停用 Verified 是信号灯。研究接下来主要看**抗污染、动态更新、真实业务场景**的基准（SWE-Bench Pro、Video-MME-v2、BABILong、RoboArena）。

2. **Verifier-centric 架构**贯穿 Reasoning / Coding / Post-training / Agentic：RLVR 成默认、PRM 发展、verifier-guided coding、self-play。**能否构造可扩展的 verifier** 正在变成比"加 compute"更关键的问题。

3. **Context rot 是 7/9 个方向的共同瓶颈**（Agentic、Harness、Coding、Multimodal、Long-context、World Models、Post-training long-horizon）。短期靠 compaction + memory agent 绕开，长期需要混合架构（Mamba/Jamba + sparse KV）真正解决。

4. **端侧与云端的距离在数据效率上**而非参数规模：DeepSeek V3 MoE + MLA、BitNet 原生 1.58bit、Phi-4 合成数据——下一个 10× 降本不再靠硬件，而靠训练目标和表征效率。

5. **开源与闭源差距≠模型能力差距**。开源在单点 benchmark 已追平（DeepSeek-R2 AIME、Qwen3-Coder、Holo3 OSWorld），但在**长时程 agentic、复杂 harness 集成、企业级可靠性**上仍有 6–12 个月代差。

6. **物理世界是最后的壁垒**。所有 6 个"偏数字"方向（Reasoning/Coding/Agentic/Harness/Long-context/Post-training）都在加速，但 World Models + Multimodal + VLA 的进度受真机数据量和物理先验缺失双重约束，3 年内更可能的是"demo 场景 → 工厂规模"的渐进突破，而非"通用家用机器人"的跳跃。
